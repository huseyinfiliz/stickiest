# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately using
[GitHub's security advisory form](https://github.com/huseyinfiliz/stickiest/security/advisories/new).
If private reporting is unavailable, email **mysuperuser01@gmail.com**.

Include the affected version, the permissions required, reproducible steps, and the
observed impact. Please avoid publishing exploit details in a public issue before
a fix is available.

## Maintenance

Use the latest patch release for your supported Flarum major version. Security
reports affecting either release line are welcome; the affected versions and
available fixes will be documented in the corresponding advisory.

Dependency updates are proposed by Dependabot and reviewed through the project's
automated checks. Dependency scanning complements the authorization and moderation
regression tests; it does not replace them.
